📋 How to Update the User List

Step 1: Download Current CSV

Click the "Download Current CSV" button below to get the current user list from GitHub.

Step 2: Edit the CSV File

Open the downloaded file in Excel or Google Sheets. You can:

  • Add new users
  • Update passwords
  • Change team access
  • Set user roles (admin or user)
  • Remove users (delete the row)

Step 3: Save as CSV

Save your changes as CSV format (not .xlsx):

  • Excel: File → Save As → CSV (Comma delimited)
  • Google Sheets: File → Download → Comma Separated Values (.csv)

Step 4: Upload to GitHub

Upload the new CSV file to GitHub to replace the old one. This page will help you prepare the file, but you must manually upload it to GitHub.

📝 CSV File Format

Required columns (in this exact order):

Email,Password,Team Access,Role katharina.stauder@bikeleasing.de,mypassword,"Sales Team,Support Team",admin john@bikeleasing.de,pass123,Tech Team,user jane@bikeleasing.de,pass456,"BLS: Support,AT: Support",admin

Important rules:

  • First row must be: Email,Password,Team Access,Role
  • Email: User's email address (must match their Aircall email)
  • Password: Any password you choose (users will use this to login)
  • Team Access:
    • Single team: Tech Team (no quotes)
    • Multiple teams: "Sales Team,Support Team" (with quotes)
  • Role: Either admin or user
    • admin - Can access admin panel to manage users
    • user - Can only manage teams
  • Team names must exactly match the team names in Aircall

⚠️ Important Security Note

After uploading to GitHub:

  • Users must refresh their browser to see changes
  • Changes take effect immediately
  • Keep your GitHub repository private if possible
  • Passwords in the CSV are visible to anyone with access to the repository
  • Only users with admin role can access this admin panel

ℹ️ This will validate your CSV format. After validation, you must manually upload the file to GitHub.
